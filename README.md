# paynote

매달 월급 받을 때 메모장으로 하던 가계 기록을 자동화하는 **개인용 로컬 웹앱**.

## 무엇을 하나 (MVP 범위)

### 포함

- **수입·지출 입력**: 월 단위로 항목 추가. 각 항목은 특정 통장(입금처/출금처)과 1:1 연결. 지출에는 선택적 카테고리 태그.
- **자동 계산**: 총수입·총지출·잔액·통장별 순변동을 실시간 계산 (저장하지 않음 → 합계 오차 원천 차단).
- **이체 계획**: 월말에 각 통장에서 저축 통장으로 "얼마 이체하면 되는지" 자동 산출 (표시용 권장안).
- **통계·추이**: 월별 수입/지출/순잔액 시계열 + 지출 카테고리 비중 파이.
- **고정지출 재사용**: ①명시적 템플릿 저장 후 적용 ②"지난 달 복제" 버튼. 둘 다 지원.
- **통장 관리**: 등록·이름 변경·아카이브(soft delete). 저축 통장 역할은 UI에서 자유 변경.
- **내보내기·백업**: JSON 전체 덤프, 로컬 스냅샷 자동 보관.

### 제외 (Phase 2 이후)

- 통장 간 실제 이체 기록(InternalTransfer) → 따라서 **통장별 누적 잔액은 근사값**. 정확한 현재 잔액은 은행 앱에서 확인.
- 월말 실측 잔액 스냅샷·계산 대조.
- 통장별 월말 목표 잔액(buffer).
- 인증·다기기 동기화·모바일 앱·은행 API 연동.

## 왜 만드나

기존 메모장 방식에서 실제로 발견된 오차(2025-09 메모 기준 -337,000원)를 보면 수동 계산의 한계가 명확하다. 수입 항목 1개·지출 항목 8개 규모에서도 합계 실수가 나는데, 월별 추이·통장별 배분까지 함께 계산하려면 프로그램이 필요하다.

## 스택

- Next.js 15 (App Router), TypeScript strict
- SQLite (better-sqlite3) + Drizzle ORM — **로컬 파일 DB**
- Tailwind CSS, Recharts
- pnpm, Node 22

## 시작

```bash
pnpm install
pnpm db:migrate    # SQLite 파일(paynote.db) 생성·마이그레이션
pnpm dev           # http://localhost:3000
```

## UX 핵심

- **매달 루틴 1~2분** — 지난 달 복제 1클릭 + 인라인 편집
- **실시간 계산** — 타이핑과 동시에 합계·이체 권장 갱신
- **이체 금액 원클릭 복사** — 은행 앱 바로 붙여넣기
- **토스트 undo** — 재확인 다이얼로그 없이 5초 내 되돌리기
- **모바일 지원** — 집 내 네트워크로 폰에서 접속 가능
- **다크/라이트** — 시스템 선호 따름

## 원칙

- **로컬 우선**: 민감한 금융 데이터는 로컬 디스크 밖으로 나가지 않는다. (ADR-0001)
- **파생값은 저장하지 않는다**: 총합·잔액·이체 계획은 모두 계산으로 얻는다. (ADR-0002)
- **단일 사용자**: 인증·권한 없음. 로컬호스트에서만 실행.
- **마찰 최소화**: 재확인 다이얼로그 대신 토스트 undo. (ADR-0007)

## 상태
