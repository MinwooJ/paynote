## 핵심 원칙

1. **입력 마찰 최소화** — 매달 반복되는 루틴이 1~2분 안에 끝나야 한다. 항목 하나 추가에 클릭 3회를 넘기지 않는다.
2. **실시간 검증** — 숫자는 타이핑과 동시에 쉼표 포맷, 합계·순잔액·TransferPlan도 즉시 갱신. 사용자가 "이 앱은 맞게 계산하고 있다"를 시각적으로 확인.
3. **실수 복구는 조용히** — 재확인 다이얼로그("정말 삭제?") 대신 **soft delete + 토스트 undo 5초** (ADR-0007).
4. **이체 실행 마찰 제거** — TransferPlan의 각 금액에 "복사" 버튼. 은행 앱에 즉시 붙여넣기 가능.
5. **모바일 지원** — `localhost`에 집 내 네트워크로 폰 접속 시에도 사용 가능. 입력 폼은 모바일 우선.
6. **저녁에도 편안하게** — 다크/라이트 토글 + `prefers-color-scheme` 자동 감지.
7. **감정 존중** — 에러 메시지는 "잘못" 같은 단어 회피. "입력을 확인해주세요" 대신 "금액은 1원 이상이어야 합니다" 같은 구체·중립 표현.

## 사용자 여정

### 여정 1 — 첫 사용 (온보딩)

첫 실행 상태: 빈 DB. `/` 진입 시 `/onboarding` 리다이렉트.

**3단계 마법사**:

1. **통장 등록** (최소 1개, 권장 3개)
   - 한국 주요 은행 프리셋 버튼(우리·국민·카카오·신한·농협·하나 등) → 클릭 시 이름 자동 채움
   - 필드: 이름, 초기 잔액(₩), 용도(일상지출/저축)
   - `openingBalanceAsOfMonth`는 **현재 월로 자동 설정** (사용자에게는 "언제 기준 잔액인가요?" 드롭다운, 기본 "오늘")
   - "+ 통장 추가" 반복
2. **저축 통장 지정 확인**
   - 2단계에서 등록한 통장 중 하나를 선택 (기본: 마지막에 등록한 savings 용도 통장)
3. **첫 달 입력 시작**
   - CTA 두 개: "이번 달 입력 시작" / "과거 달부터 기록하기"
   - 완료 후 해당 월 뷰로 이동

#### 3-a. "과거 달부터 기록하기" 선택 시 (back-entry flow)

실제 사용자는 메모로 몇 달~몇 년치 기록을 이미 가지고 있을 수 있다.

- 시스템이 **시작 월**을 물음 (예: "2024-01부터"). 월 피커.
- 시작 월을 모든 Account의 `openingBalanceAsOfMonth`로 설정 (사용자에게 "그 달의 첫 날 잔액을 입력해주세요" 안내).
- 시작 월부터 오늘까지의 빈 Month들을 일괄 생성.
- 이후 사용자가 **최신→과거 역순**으로 입력하도록 유도 (최근 기억이 더 선명해 정확). 팁 배너:
  > "💡 가장 최근 달부터 채우는 것이 수월합니다. 오래된 달은 기억이 흐려지면 넘겨도 돼요."
- 각 달 진입 시 "지난 달 복제" 버튼은 **그 달 기준의 '지난 달'**(예: 2024-06 뷰에서는 2024-05 복제)을 참조. 재귀적으로 채워가기 가능.
- 중도 이탈: 그냥 저장된 상태로 유지. 다음에 돌아와서 이어감.

**주의사항 안내 배너** (과거 기록 모드일 때 표시):
- "과거 데이터는 통장 누적 잔액 계산의 기준점이 됩니다. 시작 월의 초기 잔액을 정확히 기입하세요."
- "기억이 불확실한 항목은 비워둬도 됩니다. 통계는 기록된 달만 기반으로 계산됩니다."

### 여정 2 — 매달 반복 루틴 ⭐ (가장 중요)

월급일 전후. 사용자가 2분 안에 완료해야 하는 경로.

```
1. /  (홈) 접속
   → 오늘 기준 월 뷰로 리다이렉트 (아직 없으면 "이번 달 만들기" CTA)
2. "이번 달 만들기" 클릭
   → 기본: 지난 달 복제 (즉시 실행, 토스트 "지난 달 8개 항목 복제됨 [되돌리기]")
   → 더보기: [템플릿 A 적용 ▾] [빈 상태로 시작]
3. 복제된 항목을 보고 수정
   → 각 행 클릭으로 인라인 편집 (금액·라벨·통장)
   → 새 항목은 "+ 항목 추가"
4. 우측/하단 요약 패널이 실시간 갱신
   → 총수입, 총지출, 순잔액
   → 통장별 순변동 (+색 / -색)
   → TransferPlan (이체 권장)
5. 각 이체 라인의 [복사] 버튼으로 금액 복사
   → 은행 앱 이동 → 붙여넣기 → 이체
6. (선택) "이번 달 확인 완료" 체크
   → `Month.closedAt = now()` 기록. 편집은 여전히 가능 (소프트 플래그).
   → 월 목록·통계에서 ✓ 뱃지, 통계 페이지의 "확정된 달만" 필터 대상이 됨.
   → 체크 해제 시 `closedAt = null`.
```

### 여정 3 — 이체 계획 실행

TransferPlan 카드 구성:

```
💸 이체 권장 (2건)

  우리은행 → 카카오뱅크      ₩4,296,000    [📋 복사]
  카카오뱅크 → 국민은행       ₩1,283,000    [📋 복사]  (부족분 보충)

  이 계획을 은행 앱에서 직접 실행하세요.
  paynote은 실행 기록을 저장하지 않습니다.  [?]
```

- `[📋 복사]`: 숫자만 클립보드 (`4296000` — 쉼표·원 없음). 은행 앱 입력창 친화.
- `[?]` 툴팁: MVP에서 실행 기록을 저장하지 않는 이유. Phase 2 안내.

### 여정 4 — 과거 수정

"어? 지난 달 부모님 적금을 깜빡했네"

- 상단 월 네비게이션: `← 2026-03 | 2026-04 | 2026-05 →` + 월 피커(YYYY 그리드)
- 키보드: `[` 이전, `]` 다음, `g m` 이번 달
- 대상 월 진입 → 항목 추가·편집 (현재 월과 동일 UX)
- 편집 후 해당 월의 계산도 자동 재산출 (파생값은 저장 안 함)
- 표시: "마지막 수정: 2일 전" (audit timestamp)

### 여정 5 — 통계 확인

"올해 지출 추이와 저축 상태 보자"

- `/stats` 또는 홈 상단 "통계" 탭
- 기본 범위: 최근 12개월 (6/12/24/전체 토글)
- 카드 구성:
  1. **저축 대시보드**
     - 올해 누적 저축액 (sum of sweep amounts)
     - 월 평균 저축률 (`netBalance / totalIncome` 평균)
     - 목표 대비 (Phase 2)
  2. **월별 시계열 (선그래프)**
     - 총수입 / 총지출 / 순잔액 3선
     - 데이터 없는 달은 갭(0 아님)
  3. **지출 카테고리 비중 (파이)**
     - 현재 보는 월 기본. 범위 토글로 "최근 12개월 평균" 전환
     - null 카테고리는 "기타"
  4. **지출 TOP 5**
     - 현재 범위에서 절대금액 큰 지출 항목 5개
     - 이상치 감지("이번 달 유독 크다" 뱃지)
  5. **통장별 월간 순변동 (막대)**
     - 해당 월의 accountDelta

## 주요 인터랙션 패턴

### 금액 입력 (amount input)

- `<input type="text" inputMode="numeric" pattern="[0-9,]*">`
  - 모바일에서 숫자 키보드 자동 출력
- 타이핑과 동시에 쉼표 포맷 (controlled input, 내부값은 정수)
- Enter → 저장 / Esc → 취소
- 소수점·문자 입력 자동 제거 + 짧은 진동 힌트 (moblie haptic) — 모바일 한정
- 값 없음 시 플레이스홀더: "0 (예: 1,000,000)"

### 요약 패널 (live totals)

- 입력 영역 옆(데스크톱) 또는 하단 고정(모바일, sticky)
- 항목 추가·수정 시 즉시 갱신 (React state; DB 반영과 독립적으로 낙관적 업데이트)
- 시각적 계산 경로(옵션):
  ```
  수입 합  ₩5,416,000
    = ₩5,346,000 (월급)
    + ₩70,000   (통신비 지원)
  ```
  — 기본은 접혀 있고 "계산 펼치기" 토글. 사용자 신뢰 확보용.

### 토스트 undo (ADR-0007)

- 삭제·복제·아카이브 직후 토스트: `"삭제됨   [되돌리기]"` (5초 표시 후 자동 닫힘)
- 클릭 시 `archivedAt`을 null로 복구
- 재확인 다이얼로그는 **절대 사용하지 않음**
- 예외: Account archive 시 "이 통장을 참조하는 항목 23개는 유지됩니다" 인라인 배너 1회 표시 (다이얼로그 아님)

### Copy-to-clipboard

- TransferPlan 각 라인의 금액 옆 아이콘
- 클릭 시: 숫자만 (예: `4296000`) 클립보드로. 쉼표·원화 기호 제외 — 은행 앱 입력창 호환
- 피드백 토스트: `"4,296,000원 복사됨"`

### 카테고리 자동완성

- 지출 항목 카테고리 입력 시, 과거 사용값 기반 제안 (drop-down)
- 표시 전 정규화(trim, 공백 축약, NFC): "주거 " 와 "주거"를 같은 값으로 인식
- 새 값 입력 허용 (Enter로 확정)
- 설정 페이지 > 카테고리 관리에서 "병합" 가능 (예: "통신"과 "통신비" 합치기)

### 월 네비게이션

- 상단 바: `← 이전 | YYYY-MM | 다음 →`
- 월 이름 클릭 → 연도 그리드 팝업 (12개월 그리드, 기록 있는 달 강조)
- 키보드: `[` / `]` 이동, `g m` 이번 달, `g s` 통계, `g a` 통장 관리

### 인라인 편집

- 표의 각 행을 클릭 → 그 행이 편집 모드로 전환 (필드가 `<input>`으로 변환)
- Tab 으로 필드 이동, Enter 로 저장, Esc 로 취소
- 다른 행 클릭 시 자동 저장 (변경 있을 때만)

### 빈 상태 (empty states)

각각 안내 + 다음 행동 버튼을 함께 제공:

- **통장 없음** → 온보딩 리다이렉트
- **저축 통장 미지정** → `"저축 통장을 지정하면 이체 권장이 나타납니다 [통장 설정]"`
- **첫 달 (항목 0개)** → `"항목을 추가하거나, 지난 달이 있다면 복제하세요"` + [+ 항목 추가] [지난 달 복제]
- **통계 — 최소 2개월 필요** → `"추이를 보려면 최소 2개월 기록이 필요합니다. 현재 1개월."`
- **카테고리 없음 (파이)** → `"지출에 카테고리를 추가하면 비중 차트가 나타납니다"`
- **백업 없음** → 설정 페이지에 `"아직 백업이 없습니다 [지금 백업]"`

### 키보드 단축키 (데스크톱 우선)

| 키 | 동작 |
|---|---|
| `n` | 새 항목 추가 (현재 탭: 수입 또는 지출) |
| `Enter` | 저장 |
| `Esc` | 편집/모달 취소 |
| `[` / `]` | 이전/다음 달 |
| `g m` | 이번 달 |
| `g s` | 통계 |
| `g a` | 통장 관리 |
| `g t` | 템플릿 |
| `?` | 단축키 가이드 열기 |

### 에러 메시지 가이드라인

**좋은 예**:
- ✅ "금액은 1원 이상이어야 합니다"
- ✅ "월 형식은 YYYY-MM 입니다 (예: 2026-04)"
- ✅ "이 이름의 통장이 이미 있어요. 다른 이름을 써주세요."
- ✅ "저축 통장이 지정되지 않아 이체 권장을 만들 수 없어요. [통장 설정]"

**나쁜 예**:
- ❌ "잘못된 입력입니다" (뭐가 잘못?)
- ❌ "에러" (에러 메시지가 아님)
- ❌ "Invalid amount" (한국어 아님)

**규칙**:
- 필드 인라인, 빨간 색 + 아이콘 + 텍스트 (색맹 대응)
- 무엇이 잘못됐는지 + 어떻게 고치는지 한 문장에
- 예시 포함 (형식·범위)
- 사용자 탓 돌리는 단어 회피 ("잘못", "오류"보다 "확인", "수정")

## 접근성 & 반응형

- **키보드 전용 접근** 가능. 모든 인터랙션은 탭 이동 + Enter로 실행.
- **터치 타겟** 44px 이상 (모바일 대비).
- **시맨틱 HTML** 우선 (`<button>`, `<form>`, `<label>`). 불가피하면 `aria-label`.
- **색 + 텍스트 병기** — 색맹 대응 (적자 표시에 "부족" 텍스트 함께).
- **반응형**: 1열(≤640) / 2열(≤1024) / 3열(>1024). 모바일에선 요약 패널 하단 sticky.
- **다크·라이트**: `prefers-color-scheme` 기본 따름. 토글은 설정에서. 로컬 스토리지 저장.

## 로컬 앱 특유의 UX

- **설치·운영 안내** (설정 > 정보 탭):
  - `paynote.db` 파일 위치 표시 (복사 버튼)
  - "이 폴더를 iCloud Drive / Google Drive 아래에 두면 자동 백업됩니다" 팁
  - 포트 충돌 시 자동으로 다른 포트 시도 + 안내
- **dev vs 일상 사용**:
  - 개발: `pnpm dev` (핫리로드, 느림)
  - 일상: `pnpm start` (production 빌드, 빠름)
  - README에 한국어로 구분 명시
- **DB 설정**:
  - 설정 > 데이터 탭에서 "DB 파일 위치", "지금 백업", "JSON 내보내기", "JSON 가져오기" 제공
  - "가져오기"는 현재 DB를 덮어쓰지 않고 **새 위치에 저장 후 교체** (실수 복구 가능)

## 저축률 & 동기부여 지표

개인 가계부의 가치는 숫자보다 **맥락**에 있음. 단순 수입·지출 추이보다 다음을 우선 표시:

- **이번 달 저축률**: `netBalance / totalIncome × 100` — 36.2% 같은 %
- **올해 누적 저축**: 월별 TransferPlan sweep 금액의 연중 합 (현재 savings 통장 기준)
- **최근 12개월 평균 저축률**: 추이 상 안정적인지 확인
- **가장 큰 변동**: "지난 달 대비 지출 +15% (‒ 예산 초과 경향)" 같은 정성적 안내
- **(Phase 2)** 목표 저축률 설정 → 막대 시각화

## 안 하기로 한 것 (의도적 제외)

- **다국어 지원** — 한국어만. 개인 도구, i18n 오버헤드 낭비.
- **다중 통화** — KRW만 (ADR-0003).
- **재확인 다이얼로그** — 토스트 undo로 대체 (ADR-0007).
- **자동 클라우드 백업** — 앱은 로컬 스냅샷만. 원격은 iCloud/Drive 폴더 배치로 해결.
- **은행 API 연동** — Phase 2 이상.
- **알림 / 리마인더** — 개인 OS 캘린더가 담당.
- **예산 알림** — Phase 2 (예산 기능 자체가 Phase 2).
- **공유 / 멀티 사용자** — 단일 사용자 전제.
