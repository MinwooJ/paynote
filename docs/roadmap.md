## 최근 승격 (Mid-term → 완료)

- **PWA (Progressive Web App)** — 2026-04 적용. 매니페스트, 192/512 아이콘 (maskable 포함), apple-icon, 최소 서비스 워커. Dock / 홈 화면 설치 가능. 오프라인 완전 지원은 여전히 미구현 (설치 가능성만 충족).

## 버킷 기준

- **Near-term**: MVP 안정화 직후(~3개월) 후보. 사용자가 실제로 불편을 느꼈을 때 착수.
- **Mid-term**: 필요성이 확인되면 수개월 내 도입. 스키마 변경 또는 별도 화면이 수반.
- **Exploratory**: 필요할지 확실치 않음. 사용 패턴 관찰 후 판단.

각 항목 구성: **왜 MVP에서 뺐나 / 승격 기준 / 복잡도(S·M·L) / 참조**.

## Near-term

### InternalTransfer 명시적 모델링
- **왜 뺐나**: 사용자의 실제 메모에 이체 기록이 없어 필요성 미확인. 모델 복잡도 상승 (엔티티 1개 + UI + carry-over 로직).
- **승격 기준**: 통장별 누적 잔액 드리프트가 사용자 인식 한계 초과 시. 혹은 "지난 달 이체했나?" 같은 질문이 반복될 때.
- **복잡도**: M
- **참조**: ADR-0006

### 월말 실측 잔액 스냅샷 (MonthEndActualBalance)
- **왜 뺐나**: 사용자가 "내 입력으로만 하자"고 함. 자동 조회 불가능.
- **승격 기준**: 통장별 누적 근사값과 실제의 차이가 누적되어 신뢰 회복이 필요할 때. InternalTransfer와 묶어서 도입하면 상호 보완.
- **복잡도**: S (폼 하나, 비교 뷰 하나)

### CSV·Excel 내보내기
- **왜 뺐나**: MVP는 JSON 전체 덤프만. 대부분 케이스 커버.
- **승격 기준**: 연말정산·세무 보고용으로 CSV 요청이 발생하면.
- **복잡도**: S

### Category 정규화 테이블 승격
- **왜 뺐나**: 자유 문자열로 시작. 오타·변형 누적 전에는 오버엔지니어링.
- **승격 기준**: 사용자가 설정에서 "병합" 기능을 3회 이상 사용하거나, 통계 파이에서 중복 카테고리가 UX에 걸릴 때.
- **복잡도**: M (마이그레이션 + 병합 툴)

## Mid-term

### 통장별 `targetBalance` (월말 목표 잔액 / 버퍼)
- **왜 뺐나**: MVP는 "sweep to zero" 단순 규칙. 사용자 현재 메모에서도 명시적 버퍼 개념 확인 안 됨.
- **승격 기준**: TransferPlan 실행 후 "그래도 약간은 남겨두고 싶다"는 요구가 반복될 때.
- **복잡도**: S (Account에 nullable 필드 + TransferPlan 알고리즘 수정)

### 예산·목표 (Budget / Goals)
- **왜 뺐나**: 가계부의 자연스러운 진화 방향이지만, 도메인 모델에 새 축 추가. 사용자 현재 니즈는 "기록"이지 "계획"이 아님.
- **승격 기준**: 사용자가 "저축률 40% 목표" 같은 말을 할 때.
- **복잡도**: M

### PWA 오프라인 완전 지원
- **왜 뺐나**: 현재 최소 SW만 두어 설치 가능성만 충족. 완전 오프라인(폼 제출 큐잉·재시도)은 별도 작업.
- **승격 기준**: 폰에서 네트워크 끊긴 상태로 작업하다 데이터가 유실된 사례 발생 시.
- **복잡도**: M

### 인증 + 다기기 동기화
- **왜 뺐나**: 단일 사용자 전제. 도입 시 서버 운영·비용·보안 부담.
- **승격 기준**: 2개 이상 기기에서 동시 편집 필요가 명확할 때. Supabase·Turso·Neon 등 Postgres 호환 클라우드로 이관 가능.
- **복잡도**: L

### 인사이트 / 이상치 감지
- **왜 뺐나**: 자동화 가치가 명확하지만 튜닝 복잡 (false positive 많으면 알림 피로).
- **승격 기준**: 기본 TOP 5·이상치 뱃지에서 사용자 만족 못 할 때.
- **복잡도**: M

### 휴지통(Trash) 페이지
- **왜 뺐나**: 토스트 undo 5초로 대부분 커버. `archivedAt` 필드는 이미 있으므로 UI만 추가하면 됨.
- **승격 기준**: "5초 놓친 실수"를 수동 DB 쿼리로 복구하는 일이 반복될 때.
- **복잡도**: S

### 마감된 월(`closedAt != null`) 수정 시 경고
- **왜 뺐나**: 소프트 플래그로만 두어 마찰 없음.
- **승격 기준**: 사용자가 실수로 확정된 달을 건드려 혼란이 있을 때.
- **복잡도**: S

## Exploratory

### 은행 API 연동
- **왜 뺐나**: 한국은 오픈뱅킹 표준 있으나 개인 토큰·보안 부담 큼. 수동 입력의 신중함도 가치 중 하나.
- **승격 기준**: 수동 입력 피로가 이점을 명확히 초과할 때. 그래도 "읽기 전용" 제한 유지 추천.
- **복잡도**: L

### 다중 통화 / 국제화
- **왜 뺐나**: 단일 사용자·한국 거주 전제. 통화 로직(정수 KRW → Decimal)·UI 타이포 복잡도 크게 상승.
- **승격 기준**: 사용자가 해외 거주·외화 계좌 생길 때.
- **복잡도**: L

### 모바일 네이티브 앱
- **왜 뺐나**: 유지보수 부담 2배. PWA로 충분할 가능성.
- **승격 기준**: PWA로도 해결 안 되는 네이티브 기능(생체 인증, 위젯) 요구.
- **복잡도**: L

### 리마인더·알림
- **왜 뺐나**: 개인 OS 캘린더가 더 잘함. 앱이 알림 서버를 돌리는 건 과도.
- **승격 기준**: PWA 도입 후 web push로 간단히 붙일 수 있다면.
- **복잡도**: M

### 암호화 DB (SQLCipher)
- **왜 뺐나**: macOS FileVault 전제. 디스크 암호화가 이미 있음.
- **승격 기준**: 사용자가 다른 OS·외부 디스크·클라우드 동기화 폴더에 DB를 둘 때.
- **복잡도**: M

### 연말 인쇄 요약 / 리포트
- **왜 뺐나**: 세무 제출은 대부분 전자. 인쇄 수요 확인 안 됨.
- **승격 기준**: 연말정산 준비·보험 청구 등에서 인쇄가 필요하다는 피드백이 있을 때.
- **복잡도**: S

### 회계사·배우자 공유 뷰
- **왜 뺐나**: 단일 사용자. 외부 공유 링크 = 인증·권한 필요.
- **승격 기준**: 인증 도입 이후.
- **복잡도**: M

## 거절 (이 로드맵에 들이지 않음)

- **광고·분석 통합**: 개인 도구, 텔레메트리 전면 금지.
- **AI 자동 분류**: 카테고리 자동 분류는 개인 취향·맥락 민감. 잘못 분류하면 더 귀찮음. 수동 유지.
- **게이미피케이션**: 저축 배지·레벨. 가계부는 진지한 도구여야 함.
- **소셜 피드**: 완전한 거절. 단일 사용자 철학 위반.

## 언제 이 문서를 업데이트하나

- 승격: 항목을 MVP·구현 큐로 옮길 때 — 이 파일에서 제거 + architecture.md·README.md 반영.
- 신규 후보: 대화에서 "이런 기능 어때?" 나왔을 때 바로 여기에 추가 (구현 대상 아닌 아이디어 저장소).
- 거절: 한 번 고려 후 제외된 항목은 "거절" 섹션에 남겨 재제안 방지.
