## 프로젝트 한 줄 요약

paynote은 **매달 월급 받을 때 메모장으로 하던 가계 기록을 자동화하는 개인용 로컬 웹앱**입니다. 수입·지출을 입력하면 "남은 돈을 어느 통장에 얼마 보낼지" 자동 계산하고, 월별 추이와 저축률 통계를 보여줍니다.

## 사용자 (단일 페르소나)

- 30대 직장인 1인, 본인만 사용 — 인증·권한·공유 없음.
- 통장 3개: 우리은행(일상), 국민은행(일상), 카카오뱅크(저축). 저축 통장은 UI에서 다른 통장으로 변경 가능.
- 매달 수기 메모로 가계부를 써왔는데 합계 계산 실수가 잦았음 (실측: 2025-09 메모에서 약 337,000원 오차).
- 매달 "1~2분" 안에 기록을 끝내고 싶음.
- 맥북 주 사용, 가끔 아이폰으로 집 내 네트워크 접속.

## 해결하려는 문제

1. 수기 합계의 **계산 오차**.
2. **월별 추이·통계** 부재 (메모장 한계).
3. 통장별 배분 계획을 **매달 수기로 계산**해야 하는 반복 노동.

## 핵심 UX 원칙

1. **입력 마찰 최소화** — 매달 루틴 1~2분, 항목 추가는 클릭 3회 이하.
2. **실시간 검증** — 타이핑과 동시에 쉼표 포맷·합계·TransferPlan(이체 권장) 갱신. 사용자가 "이 앱이 맞게 계산하고 있다"를 즉각 확인.
3. **실수 복구는 조용히** — 재확인 다이얼로그 없음. 삭제·아카이브 시 5초간 하단 토스트 `[되돌리기]`.
4. **이체 실행 마찰 제거** — 이체 권장 각 금액 옆에 "복사" 버튼 (숫자만, 쉼표·원 제외 → 은행 앱에 즉시 붙여넣기).
5. **감정 존중** — 에러 메시지는 중립·구체적 ("잘못된 입력" ❌ / "금액은 1원 이상이어야 합니다" ✅).
6. **모바일·다크모드 기본 지원** — `prefers-color-scheme` 자동, 수동 토글.

## 기술 제약

- **스택**: Next.js 15 (App Router) + TypeScript strict + Tailwind CSS + **shadcn/ui** (Radix 기반 headless) + lucide-react + Recharts.
- **통화**: KRW 고정. 표기 `₩5,346,000` (사용자 선호).
- **폰트**: 한국어 본문 Pretendard 또는 Wanted Sans. 숫자는 `tabular-nums`로 자릿수 정렬.
- **반응형 브레이크포인트**: 모바일 ≤640px, 태블릿 641~1024px, 데스크톱 >1024px.
- **접근성**: 키보드 전용 조작 가능, 터치 타겟 44px+, 색 + 텍스트 병기 (색맹 대응), 시맨틱 HTML 우선.

## 디자인 톤

- **포지셔닝**: "개인 메모장의 깔끔한 진화". 은행 앱처럼 딱딱하지 않고, 가계부 앱처럼 캐릭터를 씌우지도 않음.
- **컬러 방향**: 라이트/다크 동시 제공. 포인트 컬러 1개 (저축·긍정 느낌 — 민트/세이지/소프트 블루 중 선택 추천). 손실·부족분은 부드러운 레드 (공격적이지 않은 톤).
- **정보 밀도**: 한 눈에 이번 달 상태 파악 가능. 불필요한 장식·그라데이션 지양.
- **숫자 우선**: 금액이 주연. 크고 명확하게. 라벨은 조연.
- **모션**: 미세하게. 숫자 갱신 시 소프트 트랜지션, 토스트 슬라이드인, 입력 포커스 외곽선 전환.

## 디자인이 필요한 화면 (우선순위 순)

### 1. 월별 뷰 ⭐ (가장 중요)

```
─ 상단 네비: [← 2026-03] [2026-04] [2026-05 →]   [월 선택 ▾]   [설정]
─ 좌측(데스크톱) / 상단(모바일):
  수입 (2)                          [+ 항목 추가]
    월급          ₩5,346,000    우리은행
    통신비 지원   ₩70,000       우리은행

  지출 (8)                          [+ 항목 추가]
    월세          ₩800,000      우리은행  (주거)
    관리비        ₩250,000      우리은행  (주거)
    신용카드      ₩1,283,000    국민은행  (카드)
    양평 땅 원금  ₩450,000      우리은행  (부채)
    청약          ₩100,000      우리은행  (저축)
    부모님 적금   ₩100,000      우리은행  (가족)
    통신비+인터넷 ₩90,000       우리은행  (통신)
    보험금        ₩90,000       우리은행  (보험)

─ 우측(데스크톱) / 하단 sticky(모바일): 요약 패널 (실시간)
  이번 달 요약
    총수입           ₩5,416,000
    총지출           ₩3,163,000
    ─────────────────────────
    순잔액           ₩2,253,000

  통장별 순변동
    우리은행         +₩4,296,000  (잉여)
    국민은행         -₩1,283,000  (부족)
    카카오뱅크       ±₩0

  💸 이체 권장 (2건)
    우리→카카오      ₩4,296,000   [📋]
    카카오→국민      ₩1,283,000   [📋]  (부족 보충)

─ 하단: [ ] 이번 달 확인 완료
```

- 항목 행은 **클릭 시 인라인 편집** (필드가 input으로 전환).
- 삭제 아이콘 클릭 시 행 제거 + 하단 토스트 `삭제됨 [되돌리기]` 5초.

### 2. 홈 대시보드 (`/`)

사용자가 접속하면 기본적으로 오늘 기준 월 뷰로 리다이렉트되지만, 별도 홈/대시보드 화면도 필요:

- 이번 달 스냅샷 카드 — 큰 숫자 3개 (수입·지출·순잔액) + 변동 화살표 (전월 대비).
- TransferPlan 요약 카드 — 이체 건수와 총액, [전체 보기] 버튼.
- 빠른 진입: `[이번 달 수정]` `[통계]` `[통장 관리]`.
- 최근 12개월 저축률 미니 스파크라인.

### 3. 통계 뷰 (`/stats`)

4 카드:

- **저축 대시보드**: 이번 달 저축률 (%), 올해 누적 저축액, 최근 12개월 평균 저축률.
- **월별 시계열 선그래프**: totalIncome / totalExpense / netBalance 3선. 범위 토글 (6/12/24개월 · 올해 · 작년 · 전체 · 직접 지정).
- **연도별 합계 표**: 선택 범위의 연도마다 수입·지출·순잔액·저축률·기록 개월 수.
- **지출 카테고리 파이**: 현재 월 또는 최근 12개월 평균 토글. null은 "기타".
- **지출 TOP 5**: 범위 내 최대 금액 항목. 이상치(±2σ) 뱃지.

### 4. 온보딩 (`/onboarding`) — 3단계 마법사

- Step 1 통장 등록: 한국 주요 은행 프리셋 버튼 (우리·국민·카카오·신한·농협·하나 등) + 수동 입력. 필드: 이름, 초기 잔액, 용도(일상/저축).
- Step 2 저축 통장 지정 확인.
- Step 3 첫 달 시작 방법: `[이번 달 시작]` / `[과거 달부터 기록]`.

### 5. 통장 관리 (`/accounts`)

- 목록: 이름, 역할, 초기 잔액, 현재 근사 잔액 + "근사값" 뱃지, 마지막 사용.
- 작업: 이름 변경(인라인), 아카이브(toast undo), 저축 통장 전환(한 번에 1개), 초기 잔액 재설정(rebase).

### 6. 템플릿 관리 (`/templates`)

- FixedTemplate 목록. 각 템플릿 내부에 Item들 (수입·지출 섞여 있음).
- 각 템플릿에 "적용" 버튼 → 현재 월로 복사.

### 7. 설정 (`/settings`)

- 테마 (시스템/라이트/다크).
- 데이터: DB 파일 경로 표시 + 복사, `[지금 백업]`, `[JSON 내보내기]`, `[JSON 가져오기]`.
- 앱 정보 / 버전.

## 주요 인터랙션 상세

| 인터랙션 | 동작 |
|---|---|
| 금액 입력 | `<input inputMode="numeric">`, 타이핑과 동시 쉼표 자동. 내부값은 정수. |
| 인라인 편집 | 행 클릭 → 필드가 input으로. Tab 이동, Enter 저장, Esc 취소. |
| 토스트 undo | 삭제/복제/아카이브 후 5초 토스트 `"삭제됨 [되돌리기]"`. sonner 단일 큐. |
| 복사 버튼 | TransferPlan 각 라인 금액 옆 아이콘. 클릭 시 숫자만 클립보드 → 토스트 `"₩4,296,000 복사됨"`. |
| 월 네비 | 상단 바 `← YYYY-MM →`, 월 이름 클릭 시 연도 그리드 팝업 (기록 있는 달 강조). |
| 키보드 단축키 | `[` `]` 월 이동, `n` 새 항목, `g m` 이번 달, `g s` 통계, `?` 도움말. |

## 빈 상태 (Empty States)

각각 안내 + 다음 행동 CTA:

- 통장 없음 → 온보딩 리다이렉트.
- 저축 통장 미지정 → "저축 통장을 지정하면 이체 권장이 나타납니다" `[통장 설정]`.
- 항목 0개 → "항목을 추가하거나, 지난 달이 있다면 복제하세요" `[+ 항목]` `[지난 달 복제]`.
- 2개월 미만 통계 → "추이를 보려면 최소 2개월 기록이 필요합니다".
- 카테고리 0개 (파이) → "지출에 카테고리를 추가하면 비중 차트가 나타납니다".

## 디자인 결과물 요청

1. **하이파이 시안** — 위 7개 화면 (라이트/다크 모두).
2. **반응형** — 모바일(≤640) / 태블릿(≤1024) / 데스크톱(>1024) 각 주요 3개 화면.
3. **주요 인터랙션 플로우 시퀀스**:
   - (a) 월별 뷰에서 지출 추가 → 실시간 요약 갱신 → TransferPlan 재계산
   - (b) 항목 삭제 → 토스트 undo → 복구
   - (c) 온보딩 3단계 진행
4. **디자인 토큰** — Tailwind config에 옮길 수 있는 형식으로 (colors, spacing, radius, shadow, typography, motion).
5. **shadcn/ui 컴포넌트 커스터마이징 가이드** — 사용할 컴포넌트 목록 + paynote 테마 적용 예시.

## 하지 않아도 되는 것

- 로고·브랜딩 자산 (간단한 워드마크 정도면 충분).
- 마케팅 페이지·랜딩.
- 다국어 UI (한국어만).
- 다중 통화 UI (KRW만).
- 신규 아이콘 (lucide-react 사용).
